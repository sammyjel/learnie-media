Privacy Policy: Learnie Automation

Last updated: 12 November 2026

Learnie Automation is a private tool that the owner of the Learnie Land YouTube channel uses to manage their own YouTube channels.

What data it uses

When the owner signs in with Google, the tool receives access to the owner's own YouTube channels (YouTube Data API). It uses this only to upload videos, set titles, descriptions, thumbnails and privacy settings, and to publish scheduled videos.

How data is stored

Sign-in tokens are stored encrypted in the owner's private database. They are never sold, shared or given to anyone else, and they are not used for advertising.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Stored tokens are then deleted.

Contact

Questions: contact the Learnie Land channel through YouTube.
